# Intro to AI Coding Tools — workshop slides (November 2026)

**Beyond Chatbots: Exploring AI Coding Tools for Teaching, Learning, and Research**
Seongyong Lee · UCL Institute of Education

An introductory, case-based workshop for educators and researchers: what AI coding tools are, how they differ from
chatbots, how they can be used for teaching, learning and research, how an idea becomes a working tool, and what to
check before trusting what an AI has built (accuracy, security, research ethics, educational validity).

## Live samples

Four small tools used in the workshop, each a single HTML file in `assets/apps/` that you can open directly:

| Tool | What it shows |
|---|---|
| `cafe-roleplay.html` | A speaking-practice chatbot whose feedback style, level, wait time and first-language support are set by the teacher |
| `vocab-trainer.html` | A vocabulary trainer with Leitner boxes and a teacher-supplied word list |
| `task-logger.html` | A browser task that logs every event with a time stamp; researcher view, CSV export, ethics checklist |
| `text-explorer.html` | Word frequencies and keyword-in-context lines for a pasted text |

They are teaching demos: replies come from scripts and rules (no AI model runs inside), and all data are invented.
